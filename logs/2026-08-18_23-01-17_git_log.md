# Agent Change Log

## Task objective

Добавить слабого врага Sting Dart: преследование игрока, полоска HP, урон pulse/ракетой, смерть со взрывом осколков.

## Files created or modified

- `src/data/enemies.ts`
- `src/entities/Enemy.ts`
- `src/systems/SpawnSystem.ts`
- `src/systems/CollisionSystem.ts`
- `src/effects/DebrisBurst.ts`
- `src/scenes/GameScene.ts`
- `src/systems/WeaponSystem.ts`

## Key changes

- Данные Sting Dart: maxHull 3, tint `0x145c38`, scale 0.34, speed 160.
- SpawnSystem держит до 3 врагов с краёв поля (радиус 140 px от игрока), доспавн через 1.5 с.
- CollisionSystem: overlap снарядов с врагами; pulse −1 HP, ракета убивает сразу; снаряд деактивируется.
- HP bar 30×3 следует за кораблём; 100% / ~66% / ~33%.
- DebrisBurst: 6–10 осколков, жизнь 0.4–0.7 с, без вечных объектов.
- WeaponSystem: getter группы снарядов; shutdown не вызывает `group.destroy()`.
