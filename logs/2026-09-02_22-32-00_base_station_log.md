# Base station, stages, and checkpoints

Date: 2026-09-02

## Request

At 100 km, complete Stage 1, open a Base station shop skeleton, sell hull repair for Emeralds, launch the next stage from the station, and persist Base 100 / Base 200 as continue points in the menu.

## Implementation

- Crossing 100 km or 200 km docks the ship: combat systems stop, overlay shows `Stage N complete` and `Base station`.
- Shop is a skeleton: nine outlined slots (weapons, armor, engine). Repair buttons spend Emeralds at 50 = 100% hull (1 = +2%, 10 = +20%). No overheal.
- Next Stage hides the shop and replays the station launch intro. Distance keeps counting from the base km.
- `GameProgress` v3 stores wallet + health per base km and overwrites on dock/purchase. Menu lists Continue from Base 100 / Base 200.
- Continuing from a checkpoint opens that base with the saved snapshot, not mid-stage flight.
