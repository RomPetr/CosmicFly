## Task objective

Добавить корабль игрока в GameScene с движением WASD/стрелками, лёгкой инерцией и поворотом к курсору мыши. Без врагов, стрельбы, оружия и музыки.

## Key changes

- Включён Phaser Arcade Physics: gravity 0, без Matter.
- Процедурная текстура корабля (треугольник с ярким ядром) генерируется в PreloadScene, ключ `player-ship` в `assetKeys.ts`.
- `InputManager` объединяет WASD и стрелки в один вектор длиной ≤ 1, читает world-позицию мыши, обнуляет движение без фокуса окна.
- `Player` берёт acceleration/maxSpeed/drag из `data/ships.ts`, отталкивается от края через `collideWorldBounds` + bounce, поворачивается к прицелу.
- Для `skin-ember` применяется янтарный tint; статы от скина не меняются.
- HUD «Flight in progress» и «End flight» перенесены в углы. Esc и кнопка по-прежнему ведут в GameOver.
