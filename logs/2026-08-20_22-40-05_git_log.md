# Agent Change Log

## Task objective

Уменьшить Ash Chunk в пять раз и добавить отдельные каменные осколки для обычных и смертельных попаданий.

## Files created or modified

- `src/data/meteors.ts`
- `src/effects/MeteorDebrisBurst.ts`
- `src/systems/CollisionSystem.ts`
- `src/scenes/GameScene.ts`

## Key changes

- Масштаб Ash Chunk изменён с `0.5–0.8` на `0.1–0.16` без изменения локального радиуса коллайдера.
- Добавлены малые bursts: 3–5 осколков, 180–350 мс, скорость 50–140, размер 1–2 px.
- Добавлены bursts уничтожения: 14–22 осколка, 450–900 мс, скорость 90–300, размер 1–4 px.
- Collision callback вызывается один раз до деактивации метеорита и выбирает только один эффект по признаку уничтожения.
- Очистка эффекта добавлена в безопасный POST_RENDER-переход и не выполняется в SHUTDOWN.
