## Key changes

- Обработчик End flight / Esc только ставит флаг, гасит input, паузит physics, отключает overlap и подписывается на `Phaser.Core.Events.POST_RENDER`.
- `scene.start(GameOver)` вызывается из POST_RENDER после `world.resume()`, деактивации снарядов/врагов и остановки DebrisBurst.
- `onShutdown` снимает ESC и POST_RENDER, не трогает physics bodies и не вызывает `stop()` систем.
- `WeaponSystem.stop` / `SpawnSystem.stop` деактивируют тела только при active-сцене; не пропускают деактивацию из‑за `world.isPaused`.
- `CollisionSystem` хранит overlap collider и `destroy()` его в `stop()` на живой сцене.
- `DebrisBurst.stop` уничтожает шейпы только если сцена active; в SHUTDOWN только `pieces.length = 0`.
