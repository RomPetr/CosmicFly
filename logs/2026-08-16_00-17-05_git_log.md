## Key changes

- Добавлены Phaser 3.90.0, TypeScript 5.9.3, Vite 6.4.3.
- `main.ts` только создаёт `Phaser.Game` из `gameConfig`.
- Регистрация сцен: Boot → Preload → Menu → Game → GameOver → Menu.
- `GameState` хранит `bestScore: 0` и `selectedSkinId: "skin-ember"` как модульный экземпляр, не синглтон Phaser.
- Музыка и боевые сущности не добавлялись.
- Скрипты: `dev`, `build`, `preview`, `typecheck`.
