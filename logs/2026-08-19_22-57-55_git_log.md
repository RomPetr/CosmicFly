Подключить OGG SFX через Phaser AudioManager: pulse, ракеты, engine idle/thrust. Без конвертации, без Howler, без музыки.

## Key changes

- Добавлены `SoundKeys`/`SoundPaths` на все 6 ogg.
- Preload грузит audio; `loaderror` по audio — `console.warn`, сцена идёт в Menu.
- `AudioManager`: `startFlight`/`updateThrust`/`playSfx`/`stopFlight`; SFX через `sound.play` (overlap); loops не play() каждый кадр.
- WeaponSystem играет SFX только после реального spawn в `spawnVolley`.
- `stopFlight` на POST_RENDER-выходе и SHUTDOWN, без `disableBody`.
- Menu Play вызывает `this.sound.unlock()`.
