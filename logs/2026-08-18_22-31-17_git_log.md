## Key changes

- Скопированы только три PNG Kenney (не пакет целиком, не Sprites X2). Атрибуция CC0, Kenney.nl.
- Ключи и пути текстур в `assetKeys.ts`; Preload грузит PNG из `/assets/...`; процедурная текстура корабля удалена, `pulse-bolt` оставлен.
- Игрок: `spaceShips_001`, scale `0.42`, `angleOffset` `-π/2` (нос в файле вниз), `muzzleOffsetPx` `22`, `colliderRadius` `16` (видимый размер), tint выключен.
- `GameState.autoFire = false`. WeaponSystem не стреляет сам.
- Ввод: `isFiringPulse()` только ЛКМ, `isFiringMissile()` только Space; без фокуса оба false.
- Оружие `flare-missiles`: текстура `spaceMissiles_006`, interval 450, speed 380, damage 3, lifetime 1400, scale 0.95, `angleOffset` `+π/2` (нос в файле вверх).
- Два независимых кулдауна, общий пул снарядов maxSize 40. `Projectile.fire` меняет текстуру, масштаб и смещение угла; скорость по aim, не по визуальному offset.
- `stop()` деактивирует снаряды, group не destroy. Esc / End flight → Game Over. Space не завершает забег.
