# Визуальный стиль CosmicFly

Предварительный гайд по палитре и спецэффектам. Каталог систем, идентификаторы и конфиги эффектов — в `docs/cosmicfly-effects.md`. Этот документ фиксирует, как игра должна *выглядеть*, чтобы эффекты не разъезжались по стилю.

## Палитра

| Роль | Цвет |
| --- | --- |
| Фон | `#0b0d12` |
| Ember (янтарь корпуса и тёплого ядра) | `#ffb04a` |
| Pulse-beam / HUD cyan | `#5fd4ff` / `#7fd4ff` |

Индикатор тепла pulse-beam (заливка по `heat / 100`):

| Тепло | Цвет |
| --- | --- |
| 0% | blue `#4aa3ff` |
| 30% | green `#3ecf6a` |
| 50–70% | yellow `#f0d44a` (плато) |
| 80–100% | red `#ff4a3c` |

Между якорями — линейный lerp каналов RGB. Не подмешивать в HUD и болт посторонние неоны.

## Взрывы

Один explosion sheet: Cuzco, сетка 4×16, кадр 64×64.

Масштаб того же клипа, не второй набор:

- смерть игрока — large, `spawnBurst` scale **2.4**;
- попадание ракеты — compact, scale около **0.55**.

Shake — только урон по игроку, смерть босса и крупный взрыв. Мелкие убийства не трясут камеру.

## Искры и следы ракет

Искры ракет — костёр из сопла. Крупные additive-круги (не Phaser ParticleEmitter): белый жар, золото, Ember, пламя, алый.

- burst при старте: 14–20 искр во все стороны, радиус 3–7 px;
- поток из хвоста: конус назад ±70°, радиус 2.5–5.5 px;
- редкие угольки: 4–8 px, 360°;
- blend ADD, depth над ракетой.

Язык пламени двигателя: текстура `engine_flame`, та же Ember-семья.

Запрещены серый дым, «реалистичный» exhaust и сторонние particle pack.

## Процедурные текстуры и ассеты

Допустимы простые процедурные спрайты (pulse bolt, spark), если они читаются в палитре выше.

Сторонние файлы — только CC0 (или эквивалент) с записью в `public/assets/attribution/assets.md`. Не смешивать несовместимые паки.

## Запрет разнородных спецэффектов

Один визуальный язык на весь бой:

- не второй explosion atlas «на всякий случай»;
- не отдельный smoke pack для ракет;
- не bloom/искажения, которых нет в остальной картинке;
- не новый набор частиц на каждый тип врага или оружия.

Новый эффект либо переиспользует уже принятый клип и палитру, либо не попадает в игру.
